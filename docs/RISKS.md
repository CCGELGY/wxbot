# 使用边界与风险声明

## 非官方接入与账号风险

本项目通过微信本地数据库和第三方 Hook 实现自动读取、回复与发送图片，不是微信官方机器人接口，也未获得腾讯或微信的官方认可。

**使用非官方组件、修改客户端运行环境或进行自动化操作，可能违反平台协议并引发风控。可能后果包括验证提示、功能限制、登录限制、临时或永久封禁，以及机器人服务中断。** 是否触发及如何处理由平台决定，维护者无法预测封号概率，也无法保证解封或恢复数据。

低频、拟人回复、只在单个群使用、隐藏窗口、只做测试或不收费，都不能作为“不会封号”的依据。项目不提供规避风控、反检测或绕过封禁的承诺。

部署前应自行阅读微信客户端中展示的现行协议与账号规范，可从 [腾讯微信软件许可及服务协议官方入口](https://weixin.qq.com/agreement) 查阅；入口或内容变化时，以客户端及官方发布版本为准。本声明不把具体行为认定为已获授权。

不能接受账号受限、数据丢失或服务中断风险时，请勿部署。不要将重要业务、支付或关键社交联系依赖于此机器人及其运行账号。发现账号验证、异常登录或限制提示时，应停止自动化操作并通过官方途径处理，不要反复测试发送。

## 账号、群聊与使用行为

- 仅操作本人有权使用且获得所需授权的账号、设备和群聊；不得读取或使用他人的登录数据、数据库密钥或聊天记录。
- 部署者应向相关群成员说明机器人参与、自动回复及数据处理方式，取得必要授权；提供可以联系到的管理者和停止使用的途径。
- 不得用于垃圾信息、广告群发、刷屏、骚扰、诈骗、恶意引战、冒充他人、未经授权的监控或数据采集。
- 不得利用项目绕过平台账号限制、访问控制或其他安全措施。代码开源不等于获得平台、群成员或其他权利人的授权。
- 仅将明确配置的群加入监听范围。增加群聊前重新确认授权、数据处理范围和发送频率，避免误配目标。

## 数据、隐私与模型输出

为生成回复，程序会向配置的模型服务提交角色提示词、相关群聊上下文、成员映射及相关记忆；后台记忆提取也会处理聊天内容。联网搜索会向搜索服务发送查询，候选表情可能交给模型服务审核。请先确认服务商的数据条款、保存政策和计费方式。

本地日志、聊天历史、昵称记录、SQLite 记忆库及数据库访问所需信息可能包含个人数据。部署者负责限制访问、备份、清理及处理相关人的更正或删除请求；不要把这些文件、API Key 或运行截图直接发布到仓库和 Issue。

模型可能产生事实错误、误解黑话、记错昵称、误判对话对象或输出不恰当内容；搜索与过滤不能消除这些风险。自动回复不应被当成专业意见、事实证明或他人的真实表态。角色的吐槽和玩笑应符合群成员的接受范围，发现不当输出应及时停止并调整配置。

## 系统、费用与第三方内容

- Hook 与微信版本严格耦合；升级、旧版客户端自身缺陷、DLL 故障或网络问题都可能导致崩溃或不可用。不要在不可中断的业务环境直接试用。
- Hook 接口只能绑定本机回环，不要暴露到局域网或公网，也不要提供未经鉴权的远程转发。
- 本地数据库确认只表示检测到发送记录，不代表对方已收到或阅读；确认超时也不能直接断言绝未发出。程序不自动重试发送，以减少重复消息。
- API、图像审核、记忆提取和主动接话可能产生调用费用。部署者应自行设置预算并关注用量。
- 第三方库、Hook、角色卡和网络表情分别适用各自的许可与权利要求。收藏或下载图片不等于获得再次发布或商业使用权。
